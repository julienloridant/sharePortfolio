## ☕ Règles de nommage Java

| Élément | Convention | Exemple |
| :--- | :--- | :--- |
| **Classe** | PascalCase | `UserAccount`, `PortfolioManager` |
| **Interface** | PascalCase | `Drawable`, `Serializable` |
| **Enum** | PascalCase | `OrderStatus`, `UserRole` |
| **Méthode** | camelCase | `getUserById()`, `calculateTotal()` |
| **Variable locale** | camelCase | `userName`, `totalAmount` |
| **Paramètre** | camelCase | `userId`, `portfolioName` |
| **Constante** | SCREAMING_SNAKE_CASE | `MAX_RETRY_COUNT`, `DEFAULT_TIMEOUT` |
| **Package** | lowercase (sans séparateur) | `com.shareportfolio.utils` |
| **Attribut d'instance** | camelCase | `firstName`, `accountBalance` |
| **Attribut statique** | camelCase | `instanceCount`, `defaultValue` |
| **Variable booléenne** | camelCase, préfixe `is`/`has`/`can` | `isActive`, `hasPermission` |
| **Getter** | camelCase, préfixe `get` | `getName()`, `getBalance()` |
| **Setter** | camelCase, préfixe `set` | `setName()`, `setBalance()` |
| **Test unitaire** | camelCase, descriptif | `shouldReturnNullWhenUserNotFound()` |
